# TABLET FIELDS

This document describes all fields in the tablet dataset.
Pen fields are documented separately in PEN-FIELDS.txt.

Fields are organised into nested JSON groups. Each record looks like:

  {
    "Meta":       { ... },
    "Model":      { ... },
    "Digitizer":  { ... },      -- all tablets
    "Display":    { ... },      -- PENDISPLAY and STANDALONE only
    "Physical":     { ... },    -- all tablets
    "OtherInputs":  { ... },    -- all tablets
    "Connectivity": { ... },    -- all tablets
    "Standalone":   { ... }     -- STANDALONE only
  }

Fields prefixed with _ are system fields used for internal data management.
They are not intended to be shown to end users.


## Meta group

Internal tracking fields. Not displayed to end users.

### Meta.EntityId
A user-facing unique identifier including entity type.
Format: "BRAND.ENTITYTYPE.ID" (e.g. "WACOM.TABLET.PTK870")
Required: yes

### Meta._id
A unique record identifier.
Format: UUID v4 string (e.g. "6fda48fc-98fa-46ca-9fe1-d2c953ca70a1")
Required: yes (auto-generated)

### Meta._CreateDate
The timestamp when the record was first created.
Format: ISO 8601 datetime string (e.g. "2025-12-12T12:33:46.983Z")
Required: yes (auto-generated)

### Meta._ModifiedDate
The timestamp when the record was last modified.
Format: ISO 8601 datetime string (e.g. "2025-12-12T17:53:46.334Z")
Required: yes (auto-generated)


## Model group

Product identity and classification.

### Model.Brand
The manufacturer brand.
Values: GAOMON, HUION, SAMSUNG, UGEE, WACOM, XENCELABS, XPPEN
Required: yes

### Model.Id
The manufacturer's model identifier (e.g. "GS1161", "DTK2260K0A").
Required: yes

### Model.Name
The marketing/product name (e.g. "Kamvas 12", "Cintiq Pro 22").
Required: yes

### Model.Type
The form factor category.
Values: PENTABLET, PENDISPLAY, STANDALONE
- PENTABLET  - opaque tablet without a screen
- PENDISPLAY - tablet with an integrated display
- STANDALONE - standalone drawing computer
Required: yes

### Model.LaunchYear
The year the product was released or announced.
Format: 4-digit year string (e.g. "2022")
Required: yes

### Model.Audience
The intended market segment.
Values: Consumer, Enthusiast, Professional
Required: no

### Model.Family
A grouping name for product lines or generations (e.g. "GEN3", "INTUOS4").
Required: no

### Model.IncludedPen
The pen model(s) included with the tablet. Array of pen EntityId strings.
Example: ["HUION.PEN.PW600", "HUION.PEN.PW600S"]
Required: no

### Model.IncludedInBox
What ships in the retail box, one item per string, written as the
manufacturer lists it with its quantity. Free text; the included pen's
structured link is Model.IncludedPen.
Example: ["Drawing Display x 1", "X4 Smart Chip Stylus x 1", "Pen Nibs x 10"]
Required: no

### Model.ProductLink
URL to the manufacturer's official product page.
Required: no

### Model.Status
The current availability status of the product.
Values: ACTIVE, AVAILABLE, DISCONTINUED
Required: no


## Digitizer group

Properties of the digitizer (the drawing surface). Present on all tablet types.

### Digitizer.Type
The pen sensing technology used by the digitizer.
Values: PASSIVE_EMR, ACTIVE_EMR
- PASSIVE_EMR - electromagnetic resonance with a battery-free pen
- ACTIVE_EMR  - electromagnetic resonance with a powered pen
Required: no

### Digitizer.PressureLevels
The number of pressure levels the digitizer can detect.
Format: integer string (e.g. "8192", "16384")
Required: no

### Digitizer.Dimensions
The active drawing area dimensions.
Format: object { "Width": number, "Height": number }
Unit: mm
Required: no

### Digitizer.Density
The spatial resolution (density) of the digitizer.
Format: numeric string (e.g. "200", "157.4")
Unit: LPmm (lines per millimeter)
Required: no

### Digitizer.ReportRate
The rate at which the digitizer reports pen position.
Format: integer string (e.g. "300", "266")
Unit: Hz (reports per second)
Required: no

### Digitizer.ReportRateBluetooth
The report rate over Bluetooth, when the spec lists it separately from the
wired rate. When the spec gives only one rate, it goes in ReportRate (wired).
Format: numeric string (e.g. "133")
Unit: Hz (reports per second)
Required: no

### Digitizer.Tilt
The maximum tilt angle the digitizer can detect. A value of "0" means tilt is not supported.
Format: integer string (e.g. "60")
Unit: degrees
Required: no

### Digitizer.AccuracyCenter
(A single accuracy figure with no center/corner split is stored here.)

Pen positional accuracy at the center of the active area.
Format: numeric string (e.g. "0.3", "0.5")
Unit: mm
Required: no

### Digitizer.AccuracyCorner
Pen positional accuracy at the corners of the active area.
Format: numeric string (e.g. "2", "3")
Unit: mm
Required: no

### Digitizer.MaxHover
The maximum height above the surface at which the pen is detected.
Format: integer string (e.g. "10", "12")
Unit: mm
Required: no


## Display group

Properties of the integrated display. Present on PENDISPLAY and STANDALONE only.
The schema enforces that PENTABLET records cannot have a Display group.

### Display.PixelDimensions
The screen pixel dimensions.
Format: object { "Width": number, "Height": number }
Unit: pixels
Required: no

### Display.PanelTech
The display panel technology.
Values: IPS, TFT, AHVA, OLED, H-IPS, MVA
Required: no

### Display.Brightness
Typical brightness.
Format: integer string (e.g. "250", "350")
Unit: cd/m²
Required: no

### Display.BrightnessPeak
Peak brightness (relevant for HDR-capable displays).
Format: integer string (e.g. "900")
Unit: cd/m²
Required: no

### Display.Contrast
The contrast ratio (e.g. "1000" means 1000:1).
Format: integer string
Required: no

### Display.ColorBitDepth
The color bit depth per channel.
Values: 6, 8, 10
Unit: bits
Required: no

### Display.ColorBitDepthFRC
The color depth the manufacturer claims with FRC (frame rate control)
dithering, e.g. 10 for "8-bit + FRC" or "1.07 billion colors" on an 8-bit
panel. Set only when the spec says FRC; ColorBitDepth keeps the panel's
native depth. A true 10-bit panel has ColorBitDepth "10" and no FRC field.
Values: 8, 10
Required: no

### Display.ColorGamuts
Color gamut COVERAGE keyed by canonical gamut name: the share of the
standard's gamut the panel reproduces. Never above 100 (the schema rejects
it). Record a figure here only when the manufacturer calls it coverage, or
when it's the usual "99% sRGB" style and nothing says it's an area ratio.
Format: object { "GamutName": number, ... } (e.g. { "SRGB": 99, "ADOBERGB": 90 })
Unit: % coverage (0-100)
Canonical gamut names: SRGB, ADOBERGB, DCIP3, DISPLAYP3, NTSC, REC709
Required: no

### Display.ColorGamutAreas
Color gamut AREA (also "volume" or "ratio") relative to each standard: the
size of the panel's gamut compared with the standard's. Can exceed 100, e.g.
"120% sRGB". Not comparable with coverage: a 99% coverage panel can cover
more of sRGB than a 120% area one. Same keys as ColorGamuts.
Format: object { "GamutName": number, ... } (e.g. { "SRGB": 120 })
Unit: % of the standard's area
Required: no

### Display.Lamination
Whether the display is fully laminated (bonded to the cover glass).
Values: YES, NO
Required: no

### Display.AntiGlare
The type of anti-glare treatment on the display surface.
Values: AGFILM, ETCHEDGLASS, FILM
Required: no

### Display.AntiFingerprint
Whether the manufacturer lists an anti-fingerprint (AF) coating on the
surface (e.g. "AG + AF glass"). Leave out when not stated.
Values: YES, NO
Required: no

### Display.AntiReflection
Whether the manufacturer lists an anti-reflection (AR) coating on the
surface (e.g. "AR/AG/AF"). Leave out when not stated.
Values: YES, NO
Required: no

### Display.ResponseTime
The pixel response time.
Format: integer string (e.g. "14", "25")
Unit: ms
Required: no

### Display.RefreshRate
The screen refresh rate.
Format: integer string (e.g. "60", "144")
Unit: Hz
Required: no

### Display.ViewingAngleHorizontal
The horizontal viewing angle.
Format: integer string (e.g. "178")
Unit: degrees
Required: no

### Display.ViewingAngleVertical
The vertical viewing angle.
Format: integer string (e.g. "178")
Unit: degrees
Required: no


## Physical group

Physical characteristics. Present on all tablet types.

### Physical.Dimensions
The overall physical dimensions of the tablet. Depth may be absent if unknown.
When the spec gives the depth as a range (thinnest to thickest, e.g. "19~26.7
mm"), Depth is the maximum and DepthMin the minimum. A single depth value is
treated as the maximum (Depth).
Format: object { "Width": number, "Height": number, "Depth": number, "DepthMin": number }
Unit: mm
Required: no

### Physical.Weight
The weight of the tablet.
Format: numeric string (e.g. "735", "3900")
Unit: g
Required: no

### Physical.WeightInclStand
Whether the Physical.Weight value includes the weight of a stand.
Values: YES, NO
Required: no

The four fields below are allowed on every tablet type, but are only
filled for PENDISPLAY and STANDALONE records. Absent = unknown.

### Physical.VesaMount
Whether the device can be VESA-mounted.
Values: YES, NO
Required: no

### Physical.VesaPattern
The VESA mounting pattern(s), only when the manufacturer states them.
One entry per pattern when a device lists several.
Format: array of "<number>x<number>" strings (e.g. ["75x75"], ["75x75", "100x100"])
Unit: mm
Required: no

### Physical.Legs
Whether the device has BUILT-IN legs: legs attached to the device that
fold out. Legs that belong to a separate stand do NOT count.
Values: YES, NO
Required: no

### Physical.IncludedStand
Whether a separate stand ships in the box (e.g. Huion ST100, XP-Pen AC18).
Unrelated to Legs.
Values: YES, NO
Required: no


## OtherInputs group

Inputs other than the pen: buttons, dials, touch rings and strips, and
finger touch. Allowed on all tablet types (PENTABLET, PENDISPLAY, STANDALONE).
Shown in the Explorer as "Other Inputs". The group name is a placeholder
under discussion: https://github.com/TheSevenPens/DrawTabData/issues/48

An absent key means unknown. For the counts, "0" means explicitly none.

Hybrid controls (https://github.com/TheSevenPens/DrawTabData/issues/47):
XP-Pen's "double wheel" -- a mechanical outer ring around a touch-sensitive
inner pad -- counts as ONE dial only. Nothing is added to TouchRings for it.

### OtherInputs.Buttons
The number of buttons the user can assign a shortcut to (ExpressKeys,
shortcut keys). EXCLUDE power, Bluetooth on/off, touch on/off, and
display/OSD menu/brightness buttons. A button in the center of a touch
ring or dial counts only if the manufacturer's driver lets the user assign
it a shortcut; one that only cycles the ring/dial modes does not.
Format: integer string (e.g. "8", "0")
Required: no

### OtherInputs.MultimediaKeys
Fixed-function multimedia keys (volume, play/pause, ...). Not programmable, so
not counted in Buttons, which only counts programmable buttons.
Format: numeric string (e.g. "8")
Required: no

### OtherInputs.Scrollers
Scroll wheels / scrollers that aren't rotary dials (e.g. Huion's "Scroller").
Format: numeric string (e.g. "1")
Required: no

### OtherInputs.Dials
The number of mechanical rotary dials or wheels.
Format: integer string (e.g. "1", "2")
Required: no

### OtherInputs.TouchRings
The number of touch-sensitive (capacitive) rings, e.g. Wacom's Touch Ring.
Format: integer string (e.g. "1")
Required: no

### OtherInputs.TouchStrips
The number of touch-sensitive strips or bars.
Format: integer string (e.g. "2")
Required: no

### OtherInputs.Touch
Whether the drawing surface supports finger touch input.
(Formerly Digitizer.SupportsTouch.)
Values: YES, NO
Required: no


## Connectivity group

How the tablet connects: its ports, any permanently attached cable, and
wireless. Allowed on all tablet types (PENTABLET, PENDISPLAY, STANDALONE).

For the two list fields, an empty array [] means explicitly none, and an
absent key means unknown. Likewise Bluetooth is left out when unknown --
never write "NO" just because a spec sheet doesn't mention it.

Port types (JSON value -> label; PORT_TYPES / PORT_TYPE_LABELS in lib/schemas.ts):
  USB_C            USB-C
  MICRO_USB        Micro-USB
  MINI_USB         Mini-USB
  USB_A            USB-A
  USB_B            USB-B
  LIGHTNING        Lightning
  HDMI             HDMI
  MINI_HDMI        Mini HDMI
  DISPLAYPORT      DisplayPort
  MINI_DISPLAYPORT Mini DisplayPort
  DVI              DVI
  VGA              VGA
  DC_POWER         DC power
  AUDIO_3_5MM      3.5 mm audio
  SERIAL           Serial
  ADB              ADB
  PROPRIETARY      Proprietary

### Connectivity.Ports
The physical ports on the device, ONE ENTRY PER PORT: two USB-C ports are
two entries. Detail optionally qualifies a port (speed, protocol).
Format: array of { "Type": port type, "Detail"?: string }
  e.g. [{ "Type": "USB_C", "Detail": "Thunderbolt 4" }, { "Type": "USB_C" }]
[] = no ports; absent = unknown.
Explorer field: ConnectivityPorts ("Ports"), shown as "USB-C (Thunderbolt 4), USB-C";
"None" for [].
Required: no

### Connectivity.AttachedCable
The connector(s) at the computer end of a permanently attached (captive)
cable. A splitter cable lists each of its connectors.
Format: array of port types (e.g. ["USB_A"], ["USB_A", "HDMI"])
[] = no attached cable; absent = unknown.
Explorer field: ConnectivityAttachedCable ("Attached Cable"), formatted like Ports.
Required: no

### Connectivity.Bluetooth
Whether the device has Bluetooth.
Values: YES, NO
Required: no

### Connectivity.BluetoothVersion
Bluetooth version.
Format: numeric string (e.g. "5.2", "4.1")
Required: no

### Connectivity.Wifi
Wi-Fi standard(s) supported.
Format: string (e.g. "802.11a/b/g/n/ac", "Wi-Fi 6")
Required: no


## Power group

Power the tablet needs and supplies, as the manufacturer states it.
Allowed on all tablet types. Every field is optional; leave a field out
when the manufacturer doesn't state it -- don't derive one value from
another (e.g. don't compute InputWatts from volts x amps unless the spec
sheet itself gives watts). Battery capacity and life for standalone
devices stay in the Standalone group.

### Power.InputVoltage
The tablet's rated power input voltage (its DC or USB input, not the
wall side of the adapter).
Format: numeric string (e.g. "12", "5", "20")
Unit: V
Required: no

### Power.InputCurrent
The tablet's rated power input current.
Format: numeric string (e.g. "1.5", "3")
Unit: A
Required: no

### Power.InputWatts
The tablet's rated input power, when the manufacturer states it in watts.
Format: numeric string (e.g. "18", "65")
Unit: W
Required: no

### Power.InputSource
How the main input is supplied.
Format: one of "ADAPTER" (the AC power adapter), "USB_PD" (the computer's
USB-C Power Delivery port), "USB" (a plain USB port)
Required: no

### Power.AltInputVoltage / Power.AltInputCurrent / Power.AltInputSource
A second way to power the same tablet, for displays whose spec lists two
(e.g. Wacom Movink: USB-C PD 5 V 3 A, or AC adapter 9 V 2.77 A). Same
units and values as InputVoltage / InputCurrent / InputSource.
Required: no

### Power.ConsumptionWatts
Power consumption as the manufacturer states it (typical or rated).
Format: numeric string (e.g. "10")
Unit: W
Required: no

### Power.ConsumptionMaxWatts
Maximum power consumption, when listed separately from typical.
Format: numeric string (e.g. "26")
Unit: W
Required: no

### Power.StandbyWatts
Power consumption in standby / sleep.
Format: numeric string (e.g. "0.5")
Unit: W
Required: no

### Power.AdapterWatts
Rated output of the power adapter included in the box.
Format: numeric string (e.g. "30", "65")
Unit: W
Required: no

### Power.OutputWatts
Power the tablet can supply to a connected device, e.g. USB-C power
delivery to a laptop through the tablet.
Format: numeric string (e.g. "65")
Unit: W
Required: no

## Standalone group

Compute, battery, and hardware specs. Present on STANDALONE only.
(Wi-Fi, Bluetooth and USB moved to the Connectivity group.)
The schema enforces that non-STANDALONE records cannot have a Standalone group.

### Standalone.OS
The operating system.
Format: string (e.g. "Android 14", "Windows 11 Pro")
Required: no

### Standalone.Processor
The CPU model.
Format: string (e.g. "MediaTek Helio G99", "Intel Core i7-8559U")
Required: no

### Standalone.GPU
The discrete GPU model, if any.
Format: string (e.g. "NVIDIA Quadro P1000")
Required: no

### Standalone.RAM
Installed RAM.
Format: numeric string (e.g. "8", "16")
Unit: GB
Required: no

### Standalone.Storage
Installed storage.
Format: numeric string (e.g. "128", "512")
Unit: GB
Required: no

### Standalone.ExpandableStorage
Whether the storage can be expanded (e.g. via memory card).
Values: YES, NO
Required: no

### Standalone.MemoryCardSlot
The type of memory card slot, if any.
Format: string (e.g. "microSD", "SDXC")
Required: no

### Standalone.BatteryCapacity
Battery capacity.
Format: numeric string (e.g. "7700", "4630")
Unit: mAh
Required: no

### Standalone.BatteryLife
Rated battery life.
Format: numeric string (e.g. "12")
Unit: hours
Required: no

### Standalone.BatteryChargingWatts
Maximum charging wattage.
Format: numeric string (e.g. "33", "20")
Unit: W
Required: no

### Standalone.Speakers
Whether the device has built-in speakers.
Values: YES, NO
Required: no

### Standalone.FrontCamera
Front-facing camera resolution.
Format: numeric string (e.g. "5")
Unit: MP
Required: no

### Standalone.RearCamera
Rear-facing camera resolution.
Format: numeric string (e.g. "8", "13")
Unit: MP
Required: no
